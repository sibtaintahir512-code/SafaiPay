# SafaiPay Mobile Application (Flutter)

This directory contains the cross-platform Flutter application for **SafaiPay**, supporting both:
1. **Waste Generators (Customers):** Booking pickups, viewing AI advisory estimates, and confirming verified scale weights via OTP.
2. **Waste Collectors (*Kabaris*):** Receiving job broadcasts, on-site digital weighing with scale photo uploads, and tracking verified earnings.

## Requirements
- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0

## Getting Started
```bash
cd frontend-mobile
flutter pub get
flutter run
```
